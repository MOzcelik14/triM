# triM Klavye Kısayolları

triM, endüstri standardı NLE (Non-Linear Editor) iş akışlarını destekler. Kısayol profili uygulama içinden değiştirilebilir veya `F1` tuşuna basılarak kısayol penceresi açılabilir.

---

## 1. Oynatma ve Gezinme (Transport)

| Kısayol | İşlev |
|---|---|
| `Boşluk` | Oynat / Duraklat |
| `J` | Geri oynat (tekrar basıldığında 2x, 4x, 8x hızlanır) |
| `K` | Oynatmayı durdur |
| `L` | İleri oynat (tekrar basıldığında 2x, 4x, 8x hızlanır) |
| `Sol Ok` | 1 kare geri git |
| `Sağ Ok` | 1 kare ileri git |
| `Shift + Sol Ok` | 1 saniye geri git |
| `Shift + Sağ Ok` | 1 saniye ileri git |
| `Home` | Zaman çizgisinin en başına git (`00:00:00:00`) |
| `End` | Son klibin bitişine git |
| `I` | Kaynak monitöründe giriş noktasını işaretle (Mark In) |
| `O` | Kaynak monitöründe çıkış noktasını işaretle (Mark Out) |

---

## 2. Araçlar ve Düzenleme

| triM Varsayılan | Premiere Pro | DaVinci Resolve | İşlev |
|---|---|---|---|
| `V` | `V` | `A` | Seçim Aracı (Selection Tool) |
| `C` | `C` | `B` | Jilet Aracı (Razor / Blade) |
| `S` | `Ctrl + K` | `Ctrl + \` | Oynatma kafasının bulunduğu noktada klibi böl |
| `B` | `B` | `B` | Dalgalanma Düzenleme (Ripple Edit) |
| `R` | `R` | `R` | Hız Uzatma / Sıkıştırma (Rate Stretch) |
| `Y` | `Y` | `T` | Kaydırma Aracı (Slip Edit) |
| `U` | `U` | `U` | Geçiş Aracı (Transition) |
| `H` | `H` | `H` | El Aracı (Hand / Pan) |
| `Z` | `Z` | `Z` | Yakınlaştırma Aracı (Zoom) |
| `Q` | `Q` | `Shift + [` | Oynatma kafasının solundaki kısmı başa kadar dalgalanarak kırp (Ripple Trim Left) |
| `W` | `W` | `Shift + ]` | Oynatma kafasının sağındaki kısmı sona kadar dalgalanarak kırp (Ripple Trim Right) |
| `Delete` | `Delete` | `Backspace` | Seçili klibi sil |
| `Shift + Delete` | `Shift + Delete` | `Shift + Delete` | Seçili klibi ve boşluğu dalgalanarak sil (Ripple Delete) |

---

## 3. Proje ve Genel İşlemler

| Kısayol | İşlev |
|---|---|
| `Ctrl + N` | Yeni proje oluştur |
| `Ctrl + O` | Proje aç |
| `Ctrl + S` | Projeyi kaydet |
| `Ctrl + Shift + S` | Farklı kaydet |
| `Ctrl + I` | Medya dosyası içe aktar |
| `Ctrl + E` | Dışa Aktarma Stüdyosu'nu aç (Render / Export) |
| `Ctrl + Z` | Geri al (Undo) |
| `Ctrl + Y` veya `Ctrl + Shift + Z` | Yinele (Redo) |
| `F1` | Kısayol referans penceresini aç / kapat |
| `M` | Oynatma kafasının bulunduğu konuma işaretçi (Marker) ekle |
| `N` | Manyetik kenetlenmeyi aç / kapat (Snap Toggle) |
