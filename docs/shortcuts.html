Klavye Kısayolları

triM, endüstri standardı NLE (Non-Linear Editor) iş akışlarını destekler. Kısayol profilinizi dilediğiniz zaman uygulama içinden değiştirebilir veya F1 tuşuna basarak kısayol rehberini açabilirsiniz.

1. Oynatma ve Gezinme (Transport)

Kısayol İşlev
Boşluk (Space)Oynat / Duraklat (Play / Pause)
JGeriye doğru oynat (her basışta 2x, 4x, 8x hızlanır)
KOynatmayı anında durdur
Lİleriye doğru oynat (her basışta 2x, 4x, 8x hızlanır)
Sol Ok1 kare geriye git
Sağ Ok1 kare ileriye git
Shift + Sol Ok1 saniye geriye atla
Shift + Sağ Ok1 saniye ileriye atla
HomeZaman çizgisinin en başına git (00:00:00:00)
EndZaman çizgisindeki en son klibin bitişine git
IKaynak monitöründe giriş noktasını belirle (Mark In)
OKaynak monitöründe çıkış noktasını belirle (Mark Out)

2. Araçlar ve Düzenleme (NLE Profil Karşılaştırması)

Alışık olduğunuz Premiere Pro veya DaVinci Resolve tuş düzenini tek tıkla kullanabilirsiniz.

triM Varsayılan Premiere Pro DaVinci Resolve İşlev
VVASeçim Aracı (Selection Tool)
CCBJilet / Kesme Aracı (Razor / Blade)
SCtrl + KCtrl + \Oynatma kafası konumunda klibi böl (Split Clip)
BBBDalgalanma Düzenleme (Ripple Edit)
RRRHız Uzatma / Sıkıştırma (Rate Stretch)
YYTKaydırma Aracı (Slip Edit)
UUUGeçiş Aracı (Transition)
HHHEl / Kaydırma Aracı (Hand Pan)
ZZZYakınlaştırma Aracı (Zoom)
TTTMetin ve Yazı Aracı (Type Tool)
QQShift + [Baştan oynatma kafasına kadar dalgalanarak kırp (Ripple Trim Head)
WWShift + ]Oynatma kafasından sona kadar dalgalanarak kırp (Ripple Trim Tail)
DeleteDeleteBackspaceSeçili klibi sil
Shift + DeleteShift + DeleteShift + DeleteKlibi ve boşluğu kapatıp dalgalanarak sil (Ripple Delete)

3. Proje ve Genel Kısayollar

Kısayol İşlev

Ctrl + OVar olan .trim projesini aç

Ctrl + Shift + SProjeyi farklı kaydet
