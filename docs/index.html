LINUX · WAYLAND / X11 — RUST 2021

Kaynak koddan kurulum~/triM

01 Gerekli paketleri yükle

sudo apt update
sudo apt install build-essential pkg-config libasound2-dev libx11-dev libgl1-mesa-dev ffmpeg

02 Depoyu klonla ve derle

git clone https://github.com/MOzcelik14/triM.git
cd triM
cargo build --release
./target/release/trim

Rust / Cargo kurulu olmalıdır. Dağıtımınıza göre ek paketler gerekebilir.
